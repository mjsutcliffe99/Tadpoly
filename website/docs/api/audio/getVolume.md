# tad.audio.getVolume

Returns the master audio volume.

## Syntax

```lua
volume = tad.audio.getVolume()
```

## Arguments

None.

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `volume` | number | Current master volume between 0 and 1. |

## Example

```lua
local volume = tad.audio.getVolume()
```
